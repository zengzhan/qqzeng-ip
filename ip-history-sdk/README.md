# 🗂️ IP 数据库历史版本与工具归档 (IP History & Legacy Tools)

本目录归档了 **qqzeng-ip** 历代演进过程中的历史版本（3.0 ~ 5.0）、早期大 DAT 格式解析代码以及历史桌面查询工具。

---

## 📂 历史资产目录

| 目录 / 文件 | 说明 |
| :--- | :--- |
| **`5.0/`** | 🗂️ qqzeng-ip v5.0 多语言解析代码 |
| **`4.0/`** | 🗂️ qqzeng-ip v4.0 多语言解析代码 |
| **`3.1/`** | 🗂️ qqzeng-ip v3.1 解析代码 |
| **`3.0/`** | 🗂️ qqzeng-ip v3.0 解析代码 |
| **`big-dat/`** | 🗂️ 早期 Big DAT 格式数据解析示例 |
| **`ip-old/`** | 🗂️ 早期旧版实现源码归档 |
| **`qqzeng-ip-查询工具/`** | 🛠️ Windows 桌面离线 IP 查询演示工具 |

---

> ⚠️ **提示**：
> - 本目录主要用于历史留档与老旧系统兼容查阅。

> - 全新高性能生产环境强烈推荐使用最新旗舰 **[`../ip-qzdb-sdk`](../ip-qzdb-sdk)**。
