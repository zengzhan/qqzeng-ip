# qqzeng-ip Classic SDK — 经典版 IP 地理位置解析引擎

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](./v6.0-db/LICENSE)
[![Formats](https://img.shields.io/badge/Format-.db%20%7C%20.dat-orange.svg)](#版本矩阵与选型对比)
[![Languages](https://img.shields.io/badge/Languages-C%20%7C%20C%2B%2B%20%7C%20Rust%20%7C%20Go%20%7C%20Java%20%7C%20C%23%20%7C%20Node.js%20%7C%20PHP%20%7C%20Python%20%7C%20Ruby-brightgreen.svg)](#版本矩阵与选型对比)

本目录收录 **qqzeng-ip** 生产环境中广泛部署的两代经典二进制格式的官方多语言解析 SDK：**6.0 格式（`.db`）** 与 **2.0 格式（`.dat`）**。

全部 17 套语言实现均已完成现代化工程重构，在 **100% 向下兼容老用户历史 API** 的前提下，全面引入 **加载期完整结构校验（Fail-Closed）**、**严格 IPv4 语法解析**、**无锁只读并发架构** 与 **零拷贝/字符串池去重**，并通过千万级明文 CIDR 黄金数据集逐字节对账验证。

> **全新项目技术选型建议**：如果您正在构建全新系统，或需要同时支持 IPv4 / IPv6、自定义 Schema 元数据与 `mmap` 亚微秒级检索，推荐直接采用新一代旗舰引擎 **[`ip-qzdb-sdk`（.qzdb 格式）](../ip-qzdb-sdk)**。

| **适用场景** | 已采购 6.0 `.db` 格式全球/国内库的企业生产系统 | 已采购早期 2.0 `.dat` 格式数据包的存量系统平滑升级与维护 | 全新系统建设、IPv4/IPv6 双栈检索、超低内存多进程共享 |

## 核心架构升级亮点

* **100% 向下兼容，无缝替换升级**：完整保留各语言历史类名、包名、单例入口（`getInstance` / `Instance` / `New`）与查询方法签名，老系统无需修改业务层调用代码即可直接替换升级；同时全面新增 `from_path`（指定路径多实例，支持国内库与全球库并存）与 `from_bytes`（内存字节流加载）接口。
* **Fail-Closed 防御性安全架构**：加载阶段严格校验文件尺寸、头部偏移、全部前缀区间、二叉树跳转边界及 UTF-8 编码合法性；查询阶段内置 16 跳上限与无符号边界比较，遇到截断或损坏的数据文件立即安全拒绝，杜绝缓冲区越界、有符号整数翻转与死循环。
* **跨语言严格 IP 解析语义**：摒弃各语言底层 `inet_aton` / `ip2long` 对残缺 IP（如 `1.2.3`）或八进制前导零（如 `010.0.0.1`、`0008.8.8.8`）的歧义容忍，全部统一为单次扫描、零堆内存分配的严格点分十进制校验。
* **黄金基准数据 0 误差验证**：基于 550,671 条国内精华版 CIDR 与 2,112,893 条全球旗舰版 CIDR（每网段验证起始 IP、中点 IP、结束 IP 共 **6,338,679 次全量查询**），所有语言在 `.db` 与 `.dat` 下的查询结果与明文基准数据 100% 逐字节吻合。

## 返回数据格式规范

两代经典引擎均返回以竖线 `|` 分隔的 11 个标准地理与网络属性字段：

```text
亚洲|中国|广东|深圳|南山|中国电信|440305|China|CN|113.93029|22.53291
```

| 序号 | 字段名称 | 说明 | 示例值 |
| :---: | :--- | :--- | :--- |
| 1 | **大洲** (`continent`) | 所属地理大洲中文名称 | `亚洲` |
| 2 | **国家/地区** (`country`) | 国家或地区中文名称 | `中国` |
| 3 | **省份/州** (`province`) | 一级行政区划名称 | `广东` |
| 4 | **城市** (`city`) | 二级行政区划（地级市）名称 | `深圳` |
| 5 | **区县** (`district`) | 三级行政区划（区/县）名称 | `南山` |
| 6 | **运营商** (`isp`) | 互联网服务提供商或网络归属机构 | `中国电信` |
| 7 | **行政区划码** (`area_code`) | 中国行政区划代码（6 位）或区域编码 | `440305` |
| 8 | **国家英文名** (`country_en`) | 国家或地区标准英文名称 | `China` |
| 9 | **国家简码** (`country_code`) | ISO 3166-1 alpha-2 二位国家代码 | `CN` |
| 10 | **经度** (`longitude`) | WGS-84 地理经度坐标 | `113.93029` |
| 11 | **纬度** (`latitude`) | WGS-84 地理纬度坐标 | `22.53291` |

## 数据文件获取与授权说明

本仓库仅开源多语言解析引擎源码，不包含商业 IP 数据库二进制文件（`.db` / `.dat`）。请从 [qqzeng.com](https://qqzeng.com) 获取正式授权的数据包后，将其放置于运行目录、`data/` 目录或在初始化时通过路径参数显式传入。
