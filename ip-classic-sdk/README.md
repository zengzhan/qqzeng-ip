# 📦 IP 数据库经典版本 SDK (Classic SDKs)

本目录收纳 **qqzeng-ip** 经典且目前仍在生产环境中广泛使用的 IP 数据库解析 SDK 与源码。

---

## 📂 目录结构说明

| 目录 | 格式 | 说明 | 适用场景 |
| :--- | :---: | :--- | :--- |
| **[`v6.0-db/`](./v6.0-db)** | `.db` | **经典 6.0 格式** 多语言解析 SDK (Java / Go / C / PHP / Python / C# / Node.js 等) | 购买过 6.0 经典 IP 库的企业客户 |
| **[`v2.0-dat/`](./v2.0-dat)** | `.dat` | **早期 2.0 格式** 多语言解析源码 (高压缩紧凑二进制) | 早期 2.0 数据包老系统维护 |

---

> 💡 **全新项目技术选型推荐**：
> 如果您正在开发新系统或追求极高并发与超低延迟（< 0.08 µs），推荐使用最新一代旗舰 **[QZDB 极速解析引擎](../ip-qzdb-sdk)**。
