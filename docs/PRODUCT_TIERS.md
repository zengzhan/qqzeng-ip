## 二、商业授权许可架构 (Licensing Matrix)

以**独立法人实体**为唯一定价单元，**不限服务器数量、不限内网部署节点数、不限 API 调用频次**；首购商业授权长期有效。

| 授权类别 | 适用客群 | 授权范围与权利边界 | 计费与结算规则 |
|:---|:---|:---|:---|
| **个人版 (Personal)** | 个人开发者、独立研究者、自由职业者 | 仅限本人名下独立运营的项目与产品使用；适合独立开发评估、个人站点与离线工具 | **含在首购价内**（标准首购金额即可获得授权） |
| **企业版 (Enterprise)** | 单一独立法人实体（公司/企业） | 覆盖该企业法人名下全部内部系统、部门业务与生产服务器集群；仅限企业内网使用，不得对外分发数据文件 | **含在首购价内**（同价全量覆盖企业内部） |
| **集团版 (Group)** | 拥有多家法人子公司的集团企业 | 子公司数量不限，登记纳入集团关联主体清单即可全部合法覆盖使用 | **按法人主体计**，按需合并登记 |
| **OEM 二次分发** | 商业软件开发商、SaaS 厂商、网络安全/网关硬件厂商 | 允许将 QZDB 引擎与数据文件打包内嵌至向第三方客户销售/交付的独立软件或设备中；一次性买断永久有效；后续更新享受老客户标准价，无隐形溢价 | • 轻量级（交付 $\le 10$ 套）：**首购价 $\times 1.5$**<br>• 标准级（不限量交付）：**首购价 $\times 2.0$** |

## 三、版本规格与更新订阅

- **发版周期**：每月 1 日固定全量发版，底层数据持续每日迭代校验；
- **更新方式**：支持单次更新与包年订阅（包年自动每月邮件推送最新版，省去繁琐审批流程）；
- **合规财税**：全线支持开具 **数电增值税普通发票 / 专用发票**（企业公司抬头）。
