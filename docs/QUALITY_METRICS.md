# QZDB 数据质量指标与核验定义规范 (QUALITY_METRICS.md)

> **原则**：
> 1. 指标严格定义，**IPv4 与 IPv6 计量单位绝对分离**，严禁合成单一平均数；
> 2. 空值、拒识与错误分开统计，**值为空字符串 `""` 属于未下探或无法覆盖，不计入解析错误**；
> 3. 统计口径必须具备数学守恒性与可复现性；**不承诺任何未经核实的主观 SLA**。

---

## 一、双栈计量单位与全空间定义

### 1. IPv4 空间计量
- **计量单位**：物理有效 IPv4 地址数量（即 $2^{32 - \text{masklen}}$）；
- **全空间分母**：$2^{32} = 4,294,967,296$；
- **全球已委派分母**：扣除 IANA 特殊保留网段（约 5.92 亿）后，全球五大 RIR 实际可路由公共 IPv4 总量约为 **37.02 亿**。

### 2. IPv6 空间计量
- **严禁使用 $2^{128}$**（会导致天文数字失去物理意义）；
- **法定计量单位**：**`/32` 地址块当量**（即 $2^{32 - \text{masklen}}$）；
- **全球已分配分母**：五大 RIR 官方已分配总量（约 49.25 万块 /32 当量）；
- **拓扑有效覆盖度定义**：
  $$\text{IPv6 覆盖率} = \frac{\text{主表中与 RIS 现网 BGP 活跃广播前缀重叠且 ASN 精确匹配的网段数}}{\text{RIS 全网有效活跃 BGP 前缀总量}}$$

## 二、核心质量维度定义

### 1. 覆盖率 (Coverage Rate)
- **国家级覆盖率**：$\frac{\text{已解析出明确 country\_code 的物理 IP 数量}}{\text{全球公共物理 IP 分母}}$；
- **国内省级覆盖率**：中国大陆区域内已下探至省份（`province != ""`）的地址占比（实算值 $\ge 99.95\%$）；
- **国内地市级覆盖率**：中国大陆区域内已下探至地级市（`city != ""`）的地址占比（实算值 $\ge 99.29\%$）；
- **国内区县覆盖率**：中国大陆细化到区县级（`district != ""`）的网段占比，门禁底线为 $\ge 40.0\%$。

### 2. 拒识与空值率 (Blank Rate)
- 当网段属于国家级骨干网、跨域专线或 RIR 仅委派至省级节点时，`city` 与 `district` 必须输出 `""`；
- **拒识率**：输出 `city == ""` 的合法公网地址占比。严禁为降低拒识率而强行将省级骨干段或运营商注册总部钉死到省会城市。

### 3. 数据更新与发行节奏 (Cadence)
- **底层迭代**：内部底层数据库持续每日校验与动态维护；
- **发版节奏**：对外固定于**每月 1 日**全量构建并发行官方新版；
- **服务承诺**：不设任何主观虚假的“48小时SLA”等过度承诺，以当期全量发版产物为准。

### 4. 冲突率与一致性 (Consistency)
- **双向探针门禁 (Oracle Gate)**：发版前使用真实前缀真值作为 Oracle，比对新旧 QZDB 二进制库与 CSV，要求全量抽样 0 差异才允许发版；
- **主权一致性**：RIR 委派非 `CN` 的网段，严禁归入中国。
