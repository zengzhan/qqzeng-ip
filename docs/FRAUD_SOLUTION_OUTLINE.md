# QZDB 反欺诈与业务安全场景专用方案大纲 (FRAUD_SOLUTION_OUTLINE.md)

> **场景背景**：针对金融支付风控、电商防刷、黑产代理识别、内容合规与广告作弊阻断等核心业务场景。

---

## 一、目标客群与业务痛点

1. **金融风控与反洗钱团队**：排查异地异常登录、撞库攻击、跨国代理 IP 访问；
2. **电商/营销平台运营**：识别批量羊毛党、云机房脚本刷单、虚拟运营商流量；
3. **出海业务与广告投放商**：防范虚假点击作弊、境外恶意流量穿透、规避高风险地域封禁。

---

## 二、反欺诈核心属性矩阵 (基于 ULT 25 维画像)

在风控场景下，反欺诈引擎重点聚焦以下维度标签，执行毫秒级规则匹配：

| 关键字段 | 风控判断逻辑与策略 |
|:---|:---|
| **`usage_type`** | • `DataCenter` / `Cloud`：IDC 机房或云主机，直接降权或二次验证人机交互；<br>• `Anycast` / `CDN`：加速节点穿透审计；<br>• `Broadband` / `Mobile`：优质真人消费级流量。 |
| **`country_code` / `province`** | • 境外跨洲登录异动报警（结合业务用户常驻地）；<br>• 涉赌/涉诈重点境外高危地区拦截。 |
| **`asn` / `as_name`** | • 关联黑产高频持有的境外 VPS 提供商或特定自治域编号。 |
| **`isp`** | • 识别“移动/穿透”、“联通/IDC”等复合专线网段，精准定位代理中继。 |

---

## 三、私有化离线风控集成架构

```
[前端客户端 / 移动 App]
        │ (包含客户端 Client-IP)
        ▼
[企业风控网关 / API Gateway]
        │
        ├── QZDB 本地内存映射引擎 (零延迟微秒级查找)
        │     └── 输出: { country_code, city, usage_type, asn, isp }
        │
        ▼
[风控决策引擎 (Rule Engine)]
        ├── 规则 1: usage_type in ('Cloud', 'DataCenter') -> 触发验证码
        ├── 规则 2: country_code != 'CN' 且 用户绑定国内号 -> 拦截高危交易
        └── 规则 3: ASN in 黑名单 -> 阻断请求
```

- **数据不出境、不外传**：全量库运行于内网单机，单机 500 万+ QPS 处理能力轻松扛住业务峰值流量；
- **零外部 API 依赖**：不受第三方接口网络抖动或被风控供应商探知业务数据的影响。
